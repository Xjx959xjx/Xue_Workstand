# 秋芝2046｜B站爆款中文文案风格卡

## 内容定位

- **定位一句话**：面向普通人和“小白”的 AI 工具实战导师，用“爆肝实测 + 手把手教程 + 真实场景工作流”把复杂 AI 产品讲到能直接上手。
- **核心选题范围**：
  - AI Agent：Claude Code、OpenClaw / 龙虾、Agent Skills、飞书 AI Agent。
  - 新模型 / 新产品实测：Gemini 3、豆包 Seedance 2.0、国产 AI 助手对比。
  - AI 硬件与办公流：AI 录音卡、飞书工作流、生活助手。
- **内容不是单纯资讯**，而是解决三个问题：
  1. **它到底强在哪？**
  2. **普通人怎么用？**
  3. **值不值得投入时间 / 钱 / 工作流？**
- **人设气质**：
  - 懂技术，但不端着。
  - 会爆肝，会亲测，会帮观众省时间。
  - 既能讲 API、Agent、Skill、Benchmark，也会说“草履虫都能会”“当牛马”“领导看了都迷糊”。
- **观众默认画像**：
  - 对 AI 感兴趣，但怕安装、怕配置、怕看不懂。
  - 想用 AI 提升工作、学习、生活效率。
  - 需要中文语境、国产工具、低门槛教程和文档资料。

## 开头方式

### 1. 固定式亲切问候

常用开头带一点口音和松弛感：

- “没有啊，朋友们”
- “雷猴哇，朋友们”
- “雷好啊，朋友们”
- “Hello there / Hey folks”

这种问候不是正式播报，而是像熟人开场，立刻进入聊天状态。

### 2. 热点 + 痛点双钩子

开头通常先抛出“最近太火了”，再马上接观众的真实阻碍：

- “XX 最近真的太火了，但很多朋友还在焦急地观望，被卡在复杂安装上。”
- “不管你是不是程序员，都应该用用它。”
- “今天这期视频可能会让你全面开启 Agent 的办公方式。”
- “现在全国人民只要打开手机，免费的就能做出这些了。”

不是单纯说“新东西来了”，而是强调：**这个东西很火，而且你现在可能还不会用 / 用不上 / 不知道值不值。**

### 3. 先给结果和收益

秋芝式开头会快速告诉观众“看完能得到什么”：

- “我会带每一个小白从零开始一步步了解。”
- “看完这期视频，保准你对 CC、对 AI 都进入 next level。”
- “今天我们会通过一个逐步升级的案例来理解 Skill。”
- “我也会分享安装后的通用用法和一两个月来的养虾心得。”

重点是把长视频的价值提前说清楚：**不是来听概念，是看完能上手、能复用、能少踩坑。**

### 4. 资料包 / 文档提前放钩子

几乎每期开头都会强调“我已经帮你打包好了”：

- “我把视频中涉及到的资料都打包成了文字教程。”
- “所有资料链接和补充资料，我都做成了一个网页。”
- “测试案例和 Prompt 都放在文档里。”
- “需要的朋友评论区见了。”

这是账号非常核心的转化点：**视频负责讲透，文档负责带走复习。**

### 5. 开头 CTA 很早出现，但语气轻松

常见话术：

- “建议大家立刻收藏起来。”
- “非常值得一个点赞收藏关注哦。”
- “来吧，我们先来一个学习前的仪式，点赞收藏关注，我们出发。”
- “不看广告，我们看疗效，出发。”
- “点好收藏，关注赞，发车。”

CTA 不像硬广，而是和“长教程 / 可跟练 / 有资料”绑定。

## 句式与节奏

### 1. 极强口语化，短句推进

整体像边操作边聊天，句子短、转折多：

- “OK，模型怎么选？”
- “好，设备有了，模型选好了，终于可以开装了。”
- “放心，草履虫都能会。”
- “那问题来了。”
- “我们直接看效果。”

常用语气词很多：

- “那”
- “呢”
- “啊”
- “诶”
- “OK”
- “好啦”
- “当然啦”
- “说实话”
- “咱就是说”

### 2. 节奏是“兴奋感 + 教程感”交替

不是一直亢奋，也不是一直干讲。典型节奏：

1. 先用夸张表达制造兴趣：  
   “强到离谱”“巨巨巨巨制教程”“重新定义视频模型标准”
2. 再立刻进入结构化解释：  
   “我们从三个角度来看：第一真实感，第二编导能力，第三多模态能力。”
3. 然后给案例或操作：  
   “我们直接拿同一段提示词来看。”
4. 最后再用一句口语判断收束：  
   “高下立判吧。”

### 3. 高频编号，帮观众跟上

非常喜欢用清晰编号：

- “第一，啥都能干。”
- “第二，永久记忆。”
- “第三，自我净化。”
- “我有三大用法。”
- “我们会用三个角度来对比。”

编号让复杂技术内容变得像清单，适合 B站长视频观众暂停、收藏、复盘。

### 4. 经常预判观众疑问

文案里会主动替观众发问：

- “那有朋友就很疑惑，这不就是写提示词吗？”
- “很多朋友最大的疑问就是，手机也能录音，为什么还要多带个东西？”
- “有了解 Agent 的朋友就想问了，这个 loop 好像所有 Agent 都是这样，为什么 CC 会更好呢？”
- “那么问题来了，这样的 Agent 可以干嘛呢？”

这种写法让技术解释不枯燥，像在和弹幕互动。

### 5. 技术词必须翻译成人话

遇到复杂概念，会立刻用比喻拆解：

- 讲 Skill：用“厨师有炒菜技能，里面有流程、配方、工具、材料”来解释。
- 讲 Agent：用“大模型循环”解释输入、工具调用、结果返回。
- 讲 Harness：解释成“Agent 程序里除了大模型之外，那些让表现更好的设计”。

核心原则：**先讲术语，再用生活比喻把术语降维。**

### 6. 有强烈的现场指挥感

视频文案经常指着画面说：

- “你看这里。”
- “大家扫一眼就行。”
- “我们直接点击。”
- “这里会弹出。”
- “你瞧瞧。”
- “请看这个效果。”

这让观众感觉自己正在跟着主播一起操作，而不是听一篇文章。

## 叙事结构

### 结构一：AI 工具长教程型

适合 Claude Code、Agent Skills、OpenClaw / 龙虾管家这类内容。

**标准结构：**

1. **热点引入**  
   “XX 最近太火了，但很多人还卡在安装 / 不知道怎么用。”

2. **承诺结果**  
   “今天带每一个小白从零开始，装上它、用起来、管住它，再做高级拓展。”

3. **提前给资料包**  
   “文档、链接、补充资料都放好了，方便复习。”

4. **概念扫盲**  
   先解释它是什么，和普通 AI 有什么区别。

5. **人话类比**  
   用厨师、管家、工作伙伴、牛马等比喻降低理解门槛。

6. **安装 / 配置 / 成本选择**  
   讲设备、模型、API、国产替代、省钱方案。

7. **手把手操作**  
   一步一步点击、下载、创建文件夹、填 key、接通讯软件。

8. **进阶玩法**  
   Skill、工作流、记忆、定时任务、个性化配置。

9. **适用场景和心得**  
   告诉观众适合拿它做什么，不适合做什么。

10. **文档 CTA**  
   “需要的朋友评论区见。”

### 结构二：新模型 / 新产品实测型

适合 Gemini 3、Seedance 2.0、国产 AI 助手对比。

**标准结构：**

1. **先展示炸裂结果**  
   直接给生成视频、图像、案例效果，先让观众感受到“强”。

2. **定义评测问题**  
   “它到底强在哪？”  
   “它和海外最强模型比怎么样？”  
   “谁更适合普通人的生活场景？”

3. **说明评测维度**  
   不只看榜单，而是定几个贴近结果的维度：  
   真实感、编导能力、多模态、生活常识、人情世故、专业问题等。

4. **同题对比**  
   用同一 Prompt / 同一问题让多个模型答。

5. **逐个点评缺陷**  
   不是只夸赢家，会指出：  
   “动作混乱”“镜头没逻辑”“国内信源不足”“表格原始”“理论和现实差太远”。

6. **给出明确判断**  
   “高下立判。”  
   “这次确实是毫无争议的世界第一。”  
   “更适合生活场景的是谁。”

7. **普通人怎么用**  
   从“能力强”转到“你打开 App 后应该怎么做”。

8. **影响和机会**  
   讲它对短剧、办公、学习、内容生产、普通用户的意义。

### 结构三：办公工作流 / 硬件测评型

适合飞书 AI、AI 录音卡等。

**标准结构：**

1. **提出真实场景痛点**  
   开会多、沟通多、群里报 bug、写周报、面试记录、灵感碎片。

2. **说明产品变化不在表面参数**  
   比如 AI 录音卡重点不是“3mm 卡片”，而是“录了之后 AI 能做什么”。

3. **拆成几个具体用法**  
   - 每日巡逻
   - 自动整理 bug
   - 个人分身
   - 面试小助理
   - 碎碎念变方案

4. **用团队真实流程举例**  
   “我们团队现在就是这么用的。”

5. **强调自动化结果**  
   “你按完录音键之后，它自动做完一串动作。”  
   “一面试完 HR 的活就干完 80%。”

6. **补充风险和边界**  
   权限、安全、是否适合你的工种、是否真的值得买。

7. **给人群判断**  
   “说得多、听得多的人值得；一天说不了几句话就用免费软件够了。”

## 结尾 CTA

结尾 CTA 应该延续“资料 + 下期 + 互动”的风格，不要只说“关注我”。

### 常见结尾方向

- **资料型**  
  “今天涉及到的 Prompt、Skill、安装教程、测试案例，我都打包进文档了，需要的朋友评论区见。”

- **作业型**  
  “大家可以跟着文档先跑一遍，踩坑的地方评论区告诉我，我再统一补充。”

- **下期预告型**  
  “如果你们想看国产云部署 / Antigravity 深度教程 / 更多飞书工作流，评论区扣 1，我后面继续爆肝。”

- **支持型**  
  “这期真的做了很久，如果对你有帮助，记得点赞收藏关注，一键三连支持一下。”

- **人群判断型**  
  “如果你是经常写文档、开会、做内容、搞运营的朋友，这个真的值得试一下。”

### 可复用结尾示例

> 好啦，今天所有用到的提示词、Skill、案例和补充资料，我都已经打包成文档了，需要的朋友评论区见。  
> 如果你们想看我继续把这个工具接到更多办公场景里，也可以扣个 1。  
> 这期爆肝真的不容易，觉得有用的话，点赞收藏关注，我们下期继续发车。

## 写作禁忌

- **不要只报新闻**：不能只说“某模型发布了、参数很强”。必须给真实案例、同题对比、普通人用法。
- **不要只堆术语**：Agent、Skill、Harness、API、Benchmark 都可以讲，但一定要翻成人话，最好配类比。
- **不要假装所有人都是程序员**：要默认观众怕终端、怕配置、怕英文，所以要安抚、拆步骤、给文档。
- **不要空泛夸“很强很好用”**：必须说清楚强在哪、弱在哪、适合谁、不适合谁。
- **不要忽略成本和门槛**：秋芝风格会讲 API 贵、国产包月、省钱 Skill、免费额度、硬件值不值。
- **不要一味吹产品**：要有真实吐槽，比如“搞笑派”“动作混乱”“国内信源不足”“表格原始”。
- **不要太官方**：避免发布会式、媒体稿式语言。要有“你瞧瞧”“咱就是说”“放心草履虫都能会”的口语感。
- **不要把 CTA 做成硬广**：点赞收藏要和“长教程、资料包、跟练复习”绑定。
- **不要跳过安全提醒**：涉及飞书权限、Agent 操作电脑、医疗法律判断、外部群权限时，要提醒边界和风险。
- **不要只有结论没有过程**：这个账号的爆款不是“告诉你答案”，而是带你看测试、看操作、看推理，最后让观众觉得“我也能用”。

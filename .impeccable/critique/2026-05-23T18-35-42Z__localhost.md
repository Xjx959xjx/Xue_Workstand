## Anti-Patterns Verdict

不是典型暗黑霓虹或玻璃拟态类 AI slop，也没有明显营销页误用。主要问题是产品 UI 过度依赖 1px 边框、浅灰面、低阴影、等权按钮和小字号，导致所有模块都像线框控件。自动检测返回 4 条：3 处 width transition，以及 1 处疑似侧边框强调。

## Priority Issues

[P1] 全局视觉系统太扁。bg、panel、raised、soft 的差异很小，阴影几乎关闭，线条承担了所有层级。
Fix: 重做 tokens，给页面、导航、面板、输入区、选中态分出更明确的表面层级。

[P1] 边框密度过高。桌面截图中多个页面可视区有 50-100 个带边框元素，毛利率监控页移动端可视区 tiny text 达 315 个。
Fix: 减少 pane/card 内部框线，改用分组背景、间距、标题权重和有限的分隔线。

[P1] 导航显得廉价且移动端不稳。AppNav 使用 emoji，移动端隐藏文字后只剩平台渲染不一致的符号，数据监控子导航出现竖排突兀状态。
Fix: 换 lucide 图标，重做 active state，移动端保留短标签或底部/横向导航样式。

[P2] 主操作不够像主操作。primary 按钮仍是浅底描边按钮，和普通按钮差异不足，页面“下一步”不够明确。
Fix: 建立 primary / secondary / ghost / danger 的真实层级，采集、生成、写作、刷新等操作按风险和优先级区分。

[P2] 字体和节奏过压缩。大量 11-12px 元信息散落，页面标题、区块标题、说明、表格数据没有足够层级差。
Fix: 调整 type scale 和行高，保留密度但提高可扫读性。

[P2] 页面布局结构可用但没有情绪。三栏、双栏、卡片网格都能工作，但每页都像同一套灰框模板。
Fix: 对 library/writer/gross-margin 分别定义工作流焦点，不同页面用不同的视觉重心。

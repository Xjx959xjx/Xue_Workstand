# 对话写作、风格卡与 AI 提示词完整链路

核对时间：2026-09-10。以当前本地工作树（包含尚未提交改动）为准，写作版本 writer-v7-purpose-and-presentation，逐篇风格分析版本 4。本文为静态源码审计及本地开发配置解析，未调用线上模型，未读取或重写真实账号风格卡和转写资产。占位符表示每次请求动态注入的数据，不是删减提示词。

## 1. 结论与总流程

首稿是“资料准备 + 按用途选参考 + 一次正文生成”。选参考前可能补做大量逐篇分析；大样本库还会增加分批筛选。不存在独立的 AI 审稿→自动修稿闭环。续改一般只调用一次正文模型。

```text
风格素材上游：账号视频/项目案例 → 获取字幕或下载音视频并 ASR → 本地清洗（可选 AI 清洗）
项目视频案例还可：FFmpeg 抽帧 → 多模态画面描述 → 保存素材底稿

账号风格卡：全部可用转写 → 检查整卡缓存 → 逐篇证据分析（复用缓存）
             → 原句/顺序校验 → 全部分析 + 原卡基线 → AI 归纳风格卡 → 引文校验 → 保存
项目风格卡：指定账号的全部转写 + 项目指定素材 → 缓存检查/逐篇分析
             → 账号原卡 + 全部分析 + 素材画面底稿 → AI 归纳项目卡 → 校验保存

写作首稿：输入/文件解析 → 改写模式视频链接转写 → 支持文档读取
          → 可选联网 → 每张风格卡各自读取全部样本及分析缓存
          → 未缓存样本逐篇 AI 分析 → 去重 → 大库可选分批 AI 筛选
          → AI 任务解析+最终选样 → 引句与 ID 校验 → 装入最多 14000 字符原文参考
          → 每卡独立 AI 成稿 → 本地字数/禁词检查 → 保存独立草稿及上下文快照

续改：父版本 + 当前完整正文 + 修改要求 → 校验已存风格快照
      → 普通续改/重新校准/局部范围提示词 → 一次 AI 返回完整正文 → 新版本
手动编辑：修改正文 → 新版本（不调用 AI）
```

实际页面入口为 useWriterGeneration → startTask(kind=write-copy) → /api/jobs → jobs.ts 的 runWriteCopyJob/runWriteRevisionJob。/api/write、/api/write/stream 是复用同一 ai.ts 核心逻辑的其他入口；不能把所有接口误算成重复执行的步骤。

## 2. 每步输入、输出、触发条件

|步骤|触发/输入|输出与行为|AI|
|---|---|---|---|
|输入整理|主题/改写要求、素材输入、上传文件、风格选择|保留 originalSourceInput；分离正文与文档链接；改写缺省要求由 normalizeRewritePrompt 补入|无|
|视频资料获取|改写模式且存在待转写链接|字幕/ASR 文稿，替换为素材块；仅标题不能冒充文稿|ASR；清洗可选|
|支持资料|支持文档链接或粘贴正文|飞书 Lark CLI、企微 wecom-cli 等读取；链接文档拼接最多 20000 字符；纯粘贴无该处截断|无|
|联网研究|开启联网且有配置|中文检索结论/关键信息/来源；供各风格共用|有，可降级搜索|
|逐篇证据|本风格所属全部可用样本|用途、讲法、段落推进、转接、表达动作 JSON；缓存逐篇复用|未命中才调用|
|候选去重|逐篇分析完成|按去空白全文哈希去重；不是按热度只取前几篇|无|
|分批初筛|索引超过单批约 20000 字符，形成多批|每批适用 ID 数组；批次串行，允许全不选|每批一次|
|任务解析与选样|有可用原文；本次要求、事实、卡、候选索引|task、selected、applicableStyle、notes；没有原文时跳过并记录只用卡|一次/卡|
|准备最终参考|选样优先序|14000 字符预算；全文放得下则全文，否则取已核验连续证据；保存快照|无|
|生成首稿|唯一卡、代表样本、资料、任务、plan|一篇可直接使用正文，多卡并发独立生成|一次/卡|

|续改|父版本、保存资料/卡/样本、当前稿、要求|完整新稿及新版本；不重新联网/转写/选样|一次|

有多个风格时，共享资料先准备一次，各卡参考准备并发；所有参考准备结束后再并发成稿。项目内账号样本收集按账号顺序执行。样本分析当前并发 1，可用 STYLE_SAMPLE_ANALYSIS_CONCURRENCY 调到 1—4。

## 3. 风格卡到底是什么

账号卡和项目卡都是保存的 Markdown 风格说明（style.md），不是微调模型或独立 AI。另有逐篇分析缓存、风格元数据、写作草稿快照三层数据。写作读取已保存卡，不自动重新归纳整张卡，但会补缺失的逐篇分析。

账号卡使用 getTopTranscriptSamples(..., 'all')，虽函数名含 Top，当前调用明确是全部可用转写。整卡样本指纹未变且上次非降级时，直接复用卡，AI 调用为 0。指纹包含学习版本和配置模型签名；逐篇缓存还绑定标题和完整转写。force 跳过整卡复用，但不强制清空逐篇分析缓存。

“增量”条件是已有卡、样本新增或修改且没有样本删除；不过当前实际归纳输入仍为全部逐篇分析 + 原卡基线，不能理解成只把新样本喂给最终 AI。项目卡则聚合指定账号及素材，支持整卡/逐篇缓存，生成模式为 full/cached。项目卡归纳不要求先自动重生成各账号卡。

卡归纳要求每条写法附适用条件、动作、例外和引用；代码只验证至少有一条有效格式引用且匹配到的引用合法，未程序化验证每条规则都带引用或真正具有多样本依据。失败不会用通用卡覆盖已有卡。

代码支持主 CHAT_*（兼容 OPENAI_*）→ CHAT_FALLBACK_* → CHAT_FALLBACK_2 至 5，过滤未启用或配置不完整节点。代码默认备用模型 gpt-5.5 并不表示当前正在用它。显式步骤 medium 优先于配置 low。联网先独立 WEB_RESEARCH_*，随后可尝试未声明为 chat_completions 的已配置对话节点；当前仅独立联网节点满足条件。

模型调用失败可按配置尝试下一节点；部分流式文本已输出时不随意换节点拼接。正文或风格结果为空/失败应报错，不产出本地模板正文。联网是例外：原生搜索失败 → OpenCLI DuckDuckGo 前 8 条搜索结果 → 若仍失败，返回明确不可用说明并继续已有资料写作。

## 5. 调用次数与拥挤来源

以下不计失败重试、ASR、可选清洗/画面分析：

- 单卡、缓存齐、候选一批：任务解析选样 1 + 成稿 1 = 2 次。
- 单卡、缓存齐、候选 B 批且 B>1：B 次初筛 + 1 次选样 + 1 次成稿。
- 冷缓存 N 篇：再加 N 次逐篇分析。若 N=24、B=3，就是 29 次；这是条件示例，不是本次素材库实测。
- 无原文只有卡：1 次成稿；没有 plan，本地字数/禁词检查也缺少结构化约束。
- K 卡独立写作：累加各卡分析、筛选、选样和成稿；联网正常额外 1 次，共用研究结果。
- 账号卡首次生成：N 次逐篇分析 + 1 次归纳；全命中整卡缓存则 0 次。
- 普通续改/重新校准：1 次，不再跑任务解析；手动保存 0 次。

主要复杂度来自三处：冷样本分析被放进首稿准备；大库有分批筛选加最终选择两层；正文同时收到卡、样本、plan 和六条边界，表达约束存在重叠。尚未测量耗时，不能把这些直接当作性能结论。

另有几个产品边界值得注意：没有原文时任务解析整体跳过；selected 列表可能比实际装入正文的样本多；选样索引超过 60000 字符会失败要求缩小范围；续改跳过成稿本地字数/禁词检查；局部续改靠提示词要求保留其他段落，没有局部补丁强制合并。普通续改偏向保留当前句法，重新校准允许按保存证据重组，但系统中仍保留“表达方式以当前稿件和卡为准”这一句。

如要收敛链路，我建议优先讨论把逐篇学习移到风格卡准备阶段、首稿只保留任务选样和正文两次调用，以及合并重复表达边界；这是建议，本文没有修改业务实现。

### 6.1 逐篇原文分析：system（账号和项目案例共用）

```text
完整阅读这一篇原文，分析它实际如何表达，不生成新稿。只输出JSON。
目的和讲述方式分开记录：purposes写文本实际承担的目的，可以同时介绍、评论、引导参与；narrative.forms写吃瓜、趣事、悬念、科普等讲法。吃瓜切入与推广目的可以同时成立，不是互斥分类。
完整读到结尾再判断。不能凭标题、开头或题材排除介绍或推广用途；也不能因提到游戏就认定是推广。是否付费合作无法从文本确认时不要推断。
narrative.beats按原文顺序记录关键段落的作用及原句，允许一篇先聊争议或趣事、再介绍游戏或活动。narrative.bridges记录目的转变时怎样承接，以及借用这种衔接需要哪些真实素材；没有转接就返回空数组，不强造广告段。
bridge的before和after必须是依次出现且互不重叠的连续原句，选紧邻转接处、足以看懂承接的内容；不能拿相隔很远的两句伪装自然衔接。
结构记录开场如何引出具体问题、怎样推进与转折、如何收尾；moves记录具体表达动作及适用条件和不适用情形。
quote必须是原文连续逐字摘录，保留标点，不改字不省略；选足以展示表达动作的段落，不能只有泛泛口头禅。
不要将单篇习惯升级为账号通则，不从文本臆测镜头或配乐，不把转写错字认作口头禅。
结构：{"genre":"文体描述，允许混合","purposes":["实际目的"],"unsuitable":["需要哪些事实而当前任务可能不具备，不能仅凭讲法判定不适用"],"structure":"叙述推进方式","narrative":{"forms":["讲述方式"],"beats":[{"purpose":"这段起什么作用","quote":"20至100字连续原句"}],"bridges":[{"before":"转接前原句","after":"转接后原句","action":"怎样把前面的兴趣带到后面的内容","requires":"本次资料要具备什么才能借用"}]},"moves":[{"quote":"20至180字连续原文","action":"如何表达","when":"适用情形","avoid":"例外或限制"}],"limitations":["本篇不能支持的推断"]}。
按证据选择1至4项moves、1至5段beats、0至2处bridges，不为凑数增加规则；不逐句复述，也不要求每篇都有反转或推广。
```


```typescript
export function referenceText(candidate: WriterCandidate, budget: number) {
  if (candidate.transcript.length <= budget) return candidate.transcript;
  // Keep a bridge's intervening text together; do not splice its endpoints into a false transition.
  const spans = (candidate.analysis.narrative?.bridges || []).map(bridge => {
    const start = candidate.transcript.indexOf(bridge.before);
    const after = candidate.transcript.indexOf(bridge.after, start + bridge.before.length);
    return { start, end: after < 0 ? -1 : after + bridge.after.length };
  });
  for (const quote of styleEvidenceQuotes(candidate.analysis)) {
    const start = candidate.transcript.indexOf(quote);
    spans.push({ start, end: start + quote.length });
  }
  const prefix = "【原文过长，以下为已核验的连续证据段落，非全文】\n";
  const separator = "\n\n【另一个原文片段】\n";
  const chosen: Array<{ start: number; end: number }> = [];
  let remaining = budget - prefix.length;
  for (const span of spans) {
    if (span.start < 0 || span.end <= span.start || chosen.some(s => span.start < s.end && span.end > s.start)) continue;
    const cost = span.end - span.start + (chosen.length ? separator.length : 0);
    if (cost > remaining) continue;
    chosen.push(span); remaining -= cost;
  }
  chosen.sort((a, b) => a.start - b.start);
  return chosen.length ? prefix + chosen.map(s => candidate.transcript.slice(s.start, s.end)).join(separator) : "";
}
```

```typescript
    }
  ];

  const result = await withWebResearchTimeout(
    (signal) =>
      streamWebResearchResponseText({
        messages,
        tools: [{ type: "web_search" }],
        maxOutputTokens: WEB_RESEARCH_MAX_OUTPUT_TOKENS,
        signal,
        onDelta() {
          // Consume the Responses stream so long web searches do not sit behind an idle proxy connection.
        }
      }),
    options.signal
  );

  const text = result.text.trim();
  if (result.fallback || !text) {
    throw new Error(result.fallbackReason || "原生联网搜索未返回可用结果");
```

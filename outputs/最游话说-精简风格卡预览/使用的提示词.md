# 逐篇分析

完整阅读原文，分析这篇文案有辨识度的讲述方式。

结合原句，讲清作者怎样观察事情、组织信息和运用语言，以及这些写法产生的效果。按本篇实际特点展开，为后续归纳作者风格提供依据。

输出 JSON：
{
  "analysis": "对本篇讲述方式的连贯分析",
  "examples": [
    {
      "quote": "连续逐字摘录的原句",
      "explanation": "这段体现的写法及效果"
    }
  ]
}

# 风格卡归纳

根据多篇原作分析和原句证据，归纳一张可独立指导新主题写作的作者风格卡。

讲清作者有辨识度的观察角度、组织方式和语言特点。比较作品中的共性与变化，用少量原句说明具体写法，让写手理解后能够灵活运用。

后续写手只会获得这张卡、本次素材和用户要求。项目风格结合用户指定的要求与来源分工归纳。

输出自然连贯的 Markdown，结构和篇幅按内容需要安排。引用使用 [[来源ID]]「原句」，从提供的证据中连续摘录。只输出风格卡正文。

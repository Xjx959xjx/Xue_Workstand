# 风格卡改造：实施与验证

日期：2026-09-16。

## 已落地

- 三套提示词统一维护在 `src/lib/writer-prompts.ts`：逐篇分析、卡片归纳、首稿写作。续改同步解释规则分层，仍读取旧稿快照。
- 新卡区分 S（跨样本倾向）、C（场景写法）、O（单篇观察）。S/C 需具备支持范围、触发条件、表达动作、停止与例外；O 保留观察及未定事项。
- 生成结果逐条校验引用，S 至少需要两个不同作品。相同全文去掉空白后指纹相同的来源不重复计数；改写转载、同稿不同片段等独立性仍需人工判断。
- 相邻或重叠的已核验证据按原文位置合并，保留原始换行；不能跨过未提供的文字再拼接。来源目录可列裸 ID，但它不能充当规则证据。
- 账号归纳不再输入旧卡全文，项目归纳不再输入来源账号卡；项目引用区分账号与独立素材，避免同名 ID 混用。
- 分开逐篇分析版本与最终归纳版本。仅卡片版本变化时复用有效分析；旧分析版本变化时重新学习。日常写稿仍不补跑分析。
- 用户明确保存的偏好、原子保存、风格历史、并发冲突校验及草稿快照继续沿用。生成失败保留旧卡，不用本地模板补卡。

更新代码不会批量重新生成已有风格卡；下次生成账号或项目风格时使用新版本。正式素材库未执行风格更新。
